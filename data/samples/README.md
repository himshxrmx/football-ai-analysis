# Sample videos

Put short football clips (MP4, 10 to 60 seconds, wide camera view) in this folder. They appear under
"Use a sample video" on the Analyse page. Videos are not committed to the repository.

The demonstration clip `08fd33_0.mp4` is one of the Bundesliga clips used by the Roboflow "sports" examples
(github.com/roboflow/sports, `examples/soccer/setup.sh`). Download it with:

```bash
python scripts/download_sample.py
```
